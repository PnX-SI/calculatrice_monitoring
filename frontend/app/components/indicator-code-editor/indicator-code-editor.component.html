Fonctions

gn_mean

La fonction gn_mean retourne des valeurs moyennes selon un scope pour un objet PropertyCollection . Optionnellement la moyenne peut être pondérée en fournissant un autre objet PropertyCollection pour les poids.

Syntaxe

gn_mean(properties [, scope=Scope.GLOBAL] [, weigths=None])

[ ] indique des éléments optionnels

Arguments

properties
Un objet PropertyCollection avec des valeurs numériques.
scope
Le scope sur lequel calculer les moyennes. Il doit être supérieur au scope de la propriété.
weights
Un autre objet PropertyCollection avec des valeurs numériques pour les poids.

Exemples

Moyenne des scores des taxons observés par visite (en admettant que le protocole cible ait une propriété score_taxon au niveau des observations.

scores_moyens = gn_mean(observations.score_taxon, scope=Scope.VISIT)

L'objet retourné est une PropertyCollection de scope VISIT avec pour valeurs les moyennes des scores pour chaque visite.

En reprenant l'exemple précédent on peut aussi calculer les moyennes pondérées des scores pour chaque visite.

scores_moyens_pondérés = gn_mean(observations.score_taxon, scope=Scope.VISIT, weigths=observations.abondance)

gn_extract

La fonction gn_extract retourne les correspondances d'une propriété dans un tableau de référence.

Syntaxe

gn_extract(ref_table, origin_field, target_field, properties):

Arguments

ref_table
Un objet ReferenceTable .
origin_field
Le nom de la colonne d'entrée du tableau (contenant les valeurs de la propriété).
target_field
Le nom de la colonne de sortie du tableau (ce que l'on souhaite obtenir).
properties
Un objet PropertyCollection dont on souhaite obtenir les correspondances pour chaque valeur.

Exemples

Récupération de l'indice correspondant à chaque taxon en utilisant la PropertyCollection cd_nom des observations.

indices = gn_extract(tableau_indices, "cd_nom", "indice", observations.cd_nom)

Le tableau de référence désigné par tableau_indices doit donc avoir au moins deux colonnes : cd_nom et indice .
